# What's changed

Sport Conditions is in **Beta**: it changes often, so there are no version
numbers. Every change is also in the git history. Newest first.

## 23 October 2026
- **Surfing** 🏄: pick it in the sport menu. The 12 Newquay spots, rated
  good / OK / no on wave height (ft), swell period and direction, wind
  (offshore or light) and tide, with a Surfline link on each spot. Surf
  settings (wave sizes, period, wind) are separate from parakiting's.
- **Tide rules for any site:** "not near low water", "only near high water"
  and so on, within as many hours as you choose (replaces "not near high tide").
- **Map timeline on phones** swipes sideways under a fixed marker, like Windy.
- Removed the tide labels from the map (too crowded).

## 22 October 2026 (afternoon, from feedback #1–#3)
- **Feedback Send is one tap**, and 📝 **Your requests** shows what you've
  sent, with links. With a send code (Settings → Feedback), notes go straight
  to GitHub with no extra steps.
- **Voice notes keep every word:** the screen stays on while you talk,
  listening resumes if the screen goes off, and a half-finished note comes
  back after a reload. Each note lists every place you visited while speaking.
- The page **reopens on the tab you left**; a first visit lands on
  Overview → By day.
- **Map timeline:** finer control with a finger (one hour per small slide).
- **Map tides:** beach sites show the tide at the chosen time (↑ rising,
  ↓ falling, height).

## 22 October 2026
- **Feedback mode:** speak or type notes about the app while you use it,
  then send them to GitHub in one go (Settings → Feedback).
- **Overview "By hour" is clearer:** times sit on their own strip
  ("8h 9h…"), and only good and OK hours show a wind speed.
- The page always opens on **Overview → By day** (changed back the same day:
  it now reopens where you left it).
